# На номери

Безкоштовний калькулятор реалістичної ціни авто «на номерах»: вводиш VIN (або модель), обираєш звідки → куди, і отримуєш три сценарії (мінімум / реалістично / максимум) з розбивкою: податки, логістика, сертифікація й переобладнання, оформлення, нюанси для конкретного ринку (US/EU/JP) і порядок дій.

Напрямки: 🇺🇸 США / 🇪🇺 ЄС / 🇺🇦 Україна / 🇯🇵 Японія / 🇰🇷 Корея → 🇺🇦 Україна, 🇪🇸 Іспанія.

- VIN: NHTSA vPIC (безкоштовно, CORS). Американські VIN розпізнаються повністю; для європейських — марка, рік, завод + довідник популярних моделей.
- Курси: НБУ (live, з резервним значенням).
- Ставки: `src/data/rules.ukraine.json`, `src/data/rules.spain.json` (з датою дії та джерелами). Нюанси переобладнання: `src/data/nuances.json`. Довідник моделей: `src/data/models.json`.
- Логіка: `src/lib/calc/*`. Тести: `npx vitest run`.

```sh
npm install
npm run dev        # http://localhost:5173
npm run build
```

Усе рахується в браузері, сервера немає. Деплой — GitHub Pages через `.github/workflows/deploy.yml`.
