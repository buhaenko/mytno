# Мови, які зараз не показуються

Ці переклади повні й вивірені — вони просто не в `LOCALES`, тому не збираються і не
потрапляють у сторінки. Щоб повернути будь-яку: перенести файл на рівень вище,
додати код у `src/i18n/locales.ts` (і назву в `LOCALE_NAMES`), перезапустити
`npm run og` і `npm run build`. Нових перекладів для них ніхто не пише, поки вони тут,
тож перед поверненням звірте набір ключів з `en.ts`.
